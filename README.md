## 🚀 Быстрый старт

### 1. Установка зависимостей

```cmd
cd C:\Users\ЯНРС\Desktop\social-network\packages\frontend
npm install
```

### 2. Настройка `.env`

Создай файл `.env` в папке `frontend` (скопируй из `.env.example`):

```env
# API
PORT=8080
WS_PORT=8787
NODE_ENV=development

# JWT
JWT_SECRET=твой-секретный-ключ-минимум-32-символа
JWT_EXPIRES_IN=15m

# Админка
ADMIN_KEY=твой-админ-ключ
```

### 3. Запуск

**Вариант A — через `start.bat`** (рекомендуется):

Двойной клик по `start.bat` в проводнике. Всё запустится автоматически.

**Вариант B — вручную** (2 окна cmd):

**Окно 1 — сервер:**
```cmd
node server.js
```

**Окно 2 — веб-сервер для HTML:**
```cmd
npx serve . -l 3000
```

### 4. Открыть в браузере

- **Клиент:** http://localhost:3000
- **Админка:** http://localhost:3000/admin.html
- **API:** http://localhost:8080
- **Политика:** http://localhost:3000/privacy.html

| Тип | Описание |

|---|---|

## 🎥 Запись звонков

### Как это работает

1. Во время звонка нажми **⏺** в панели управления
2. Браузер записывает **смешанный поток** (твой + собеседника)
3. Каждые 5 сек — чанк записи → base64 → WebSocket → сервер
4. Сервер копит чанки в памяти
5. Нажми **СТОП** → сервер склеивает → сохраняет `.webm` файл
6. Оба участника получают ссылку + сообщение в чате

### Где хранятся записи

```
data/recordings/call_<timestamp>_<random>.webm
```

### Формат

- **WebM** (VP8/VP9 + Opus)
- Открывается в **Chrome**, **Firefox**, **VLC**
- ⚠️ Windows Media Player **не открывает** — используй VLC

### Ограничения

- **Максимум** 500 МБ на запись
- **Автоочистка** зависших записей через 1 час
- **Оба участника** видят, что идёт запись

## 🐛 Решение проблем

### `EADDRINUSE: address already in use :::8080`

**Причина:** порт занят другим Node-процессом.

**Решение:**
```cmd
taskkill /IM node.exe /F
node server.js
```

### `Cannot GET /admin.html`

**Причина:** `npx serve` не запущен.

**Решение:**
```cmd
cd C:\Users\ЯНРС\Desktop\social-network\packages\frontend
npx serve . -l 3000
```

### `Неверный админ-ключ`

**Причина:** ключ в `.env` не совпадает с введённым в браузере.

**Решение:** проверь `ADMIN_KEY` в `.env`.

### Крякозябры в `start.bat`

**Причина:** файл сохранён не в UTF-8.

**Решение:** открой в Блокноте → **Сохранить как** → **Кодировка: UTF-8**.

### WebSocket не подключается

**Причина:** `server.js` не запущен, или не тот порт.

**Решение:**
1. Убедись, что `node server.js` работает
2. В клиенте: **Профиль → Signal Server → Server → `ws://localhost:8787/ws` → Сохранить**

### Запись звонка не сохраняется

**Причина:** в `index.html` не добавлен клиентский скрипт.

**Решение:** добавь `<script>` для записи (см. отдельную инструкцию).

### PWA не устанавливается

**Причина:** нет иконок в `icons/`.

**Решение:** создай папку `icons/` с 4 файлами:
- `icon-192.png`
- `icon-512.png`
- `icon-maskable-512.png`
- `icon.svg`
